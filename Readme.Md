# Day 1 - Sum of Two Numbers

## 📖 Description

This is my **Day 1** program for the **100 Days of Python** challenge.

The program takes two numbers as input from the user, adds them together, and displays the result using a Python **f-string**.

## 💻 Program

```python
# Day 1 - Sum of Two Numbers

num1 = int(input("Enter the value of num1: "))
num2 = int(input("Enter the value of num2: "))

result = num1 + num2

print(f"The sum of the two numbers is {result}.")
```

## ▶️ Sample Output

```text
Enter the value of num1: 10
Enter the value of num2: 20
The sum of the two numbers is 30.
```

## 📚 Concepts Practiced

* Variables
* User Input
* Type Conversion using `int()`
* Arithmetic Operator (`+`)
* f-Strings
* `print()` Function

## 🎯 What I Learned
